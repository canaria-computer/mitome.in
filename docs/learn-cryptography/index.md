# 暗号技術の基礎知識

ここでは、暗号技術について簡単にまとめます。とりわけ暗号技術は非常に幅広い分野かつ
難解でしばしば、ソフトウェア開発者でさえミスを犯すことがあります。
より専門的になりすぎず数学的ではない概念的な整理にとどめます。

## 暗号技術の大別

暗号技術は、データをスクランブルして鍵を持たない者以外から機密性を維持する
守秘用途以外にもいくつかの技術を組み合わせた概念です。

決まった分類は存在しませんが、ここでは次のように分類します。

- 公開鍵暗号(非対称鍵暗号)
    - 守秘
    - 署名
    - 鍵共有 
- 共通鍵暗号(対称鍵暗号)
    - ストリーム暗号
    - ブロック暗号
    - メッセージ認証子(メッセージ認証符号,MAC)
        - ハッシュ関数ベースのメッセージ認証子(HMAC)
        - 暗号関数ベースのメッセージ認証子(CMAC)
- 暗号学的ハッシュ関数
- 暗号論的擬似乱数生成器(CSPRNG)
- その他特殊用途

## 公開鍵暗号(非対称鍵暗号)

公開鍵暗号(非対称鍵暗号)技術は、さらに3つにわかれます。

「守秘」は、データをスクランブルし機密にする技術です。
「署名」は、対立する当事者間においてメッセージが改ざんされておらず私有鍵の持ち主によって
真にデータが作成されたことを証明します。
「鍵共有」は、信頼できない通信経路において当事者が安全に通信をやり取りするための鍵について
安全に転送や生成する手順の技術です。

## 共通鍵暗号(対称鍵暗号)

共通鍵暗号(対称鍵暗号)は、一般的にはデータを素早く暗号化して秘匿する技術です。
なお、メッセージ認証子は直接暗号化して秘匿するものではありません。

共通鍵暗号は、暗号化について固定長のデータ単位でしか暗号化・平文化できない
ものをブロック暗号、ビットやバイト単位でできるものをストリーム暗号と区別されます。

通常平文化したメッセージについては、メッセージ認証による検証を行ってから
アプリケーションはデータを処理します。
メッセージ認証をせずに復号結果を処理すると、攻撃者が改変した暗号文を通じて、
受信者に不正な命令を実行させたり、復号結果に関する情報を引き出したりできるためです。

そのチェックするためのデータとアルゴリズムは、MACと呼ばれます。
MACは、さらにHMACとCMACに分かれます。

なお、暗号化とメッセージ認証をひとまとめに処理できる暗号アルゴリズムは
AEAD(Authenticated Encryption with Associated Data,認証付き暗号)と呼ばれます。

## 暗号学的ハッシュ関数

ハッシュ関数とは、決定的にデータの特徴を示す関数です。
この結果は、ハッシュ値またはダイジェストと呼ばれます。

決定的であるということは、同じ入力に対して同じ出力を毎回返すということです。

コンピュータサイエンスでは、(広義の)ハッシュ関数は、
データベースの問い合わせの効率化、キャッシュ制御、データの
重複排除、通信エラーの検知、分散処理などに使われます。

暗号の分野で単にハッシュ関数と呼ぶ場合、それは
「暗号学的ハッシュ関数」です。

暗号学的ハッシュ関数の特徴は、次の性質があることです。

1. 与えられたハッシュ値を出力する入力を見つけるのが極めて困難
2. 既に与えられた入力によって得られるハッシュ値と同じハッシュ値を持つ別の入力を見つけるのが困難
3. ハッシュ値が偶然一致する異なる入力の組を見つけるのが極めて困難
4. 入力データのわずか1ビットの変化であっても、ハッシュ値の出力が大幅に変わり出力について予測が困難

## 暗号論的擬似乱数生成器(CSPRNG)

現代の暗号アルゴリズムは基本的に「理想的な真の乱数」が入力される前提で構築されています。
しかしながら、コンピュータは決定的な手順に従って計算する存在であり乱数を作ることは
難しいタスクです。そのため、自然のノイズを組み合わせて乱数を生成します。
この乱数生成手順において、万が一その乱数が偏りがあったりすると鍵の探索範囲を狭めることにつながり
結果として暗号アルゴリズムの欠陥を見つけることなく内容を復元できる可能性があります。

この最もきつい試練に耐える乱数生成技術は、暗号論的擬似乱数生成器と呼ばれます。

PGPの鍵生成などで、マウスを動かすように指示したり画面が固まることがあります。
これは、裏側で可能な限り偏りのない乱数を生成するためのタスクが裏側で行われているからです。

## その他特殊用途(知識を広げたい人向け)

紹介しきれないですが、興味がある人のために関連する技術について載せます。

パスワードはハッシュ関数で保存しますがそのハッシュ関数はパスワードハッシュ化関数として
独立したアルゴリズムを利用します。

暗号資産では、ハッシュ関数によって複数のコンピュータが
計算結果について合意するPoWと呼ばれる技術があります。
そのPoWについて、専用のハッシュ関数(メモリハードハッシュ関数)が開発されていたりします。
